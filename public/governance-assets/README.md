# Governance Assets

Coloca aqui los logos, imagenes y recursos visuales del login de gobernanza.

Sugerencia de nombres:

- `logo.png`
- `logo.svg`
- `login-background.jpg`
- `login-illustration.png`

En Blade se pueden usar asi:

```blade
<img src="{{ asset('governance-assets/logo.png') }}" alt="Logo">
```
